Le retour multiple = Une fonction peut retourner plusieurs valeur (ex: résultat et erreurs). Ça remplace les Try / Catch par exemple.
=> L’approche de GO est plus explicite que les exeptions. Le flux est métrisé !

Fonction variadique
Def: Une fonction variadique est une fonction qui accepte un nombre variable d'arguments.

Closure
Def: Une fonction qui se souvient de l’environnement dans lequel elle a été créée

Fall through
Def: Permet de ne pas s’arrêter au premier cas par exemple dans un switch case. Contrairement à d’autres langages, le fall through est automatique. Dans go ça permet de le rendre explicite pour plus de clarté afin d’éviter des bugs inutiles

Pascal Case debute par une majuscule : partagé
